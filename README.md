# Premier League Predictor

A Python project focused on exploring English Premier League football data and gradually developing a match outcome prediction system.

## Project Status

**In development — Initial data exploration**

The project currently contains historical match data and an initial Python script for loading the dataset.

## Objectives

- Explore and understand historical Premier League match data.
- Learn data analysis techniques using Python and Pandas.
- Develop and evaluate match outcome prediction models.
- Document the development process and results.

## Technologies

- Python
- Pandas
- Git and GitHub

## Getting Started

Create and activate a Python virtual environment, then install the dependencies:

```bash
python -m pip install -r requirements.txt
```

Run the initial exploration script from the project root:

```bash
python src/01_explore_data.py
```

## Current Dataset

Historical Premier League match data for the 2025/26 season, stored in `data/raw/E0_2526.csv`.

## Development

This project is being developed incrementally, with an emphasis on learning, reproducibility, and understanding the methods used.
